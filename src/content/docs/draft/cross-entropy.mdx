### Intro
<br/>

- 거대 언어 모델(LLM)의 사전 학습(Pre-training) 및 미세 조정(SFT)에서 가장 널리 사용되는 기본 손실 함수는 <strong>Multi-Class Cross-Entropy Loss (Categorical Cross-Entropy)</strong>이다.
- 언어 모델링의 목표는 수만 개의 어휘 사전(Vocabulary) 확률 분포 중 바로 다음 위치에 올 정답 토큰(Target Token)을 정확하게 예측하는 것이다.
- 본 문서에서는 Multi-Class Cross-Entropy 손실 함수의 수학적 정의, 입력/정답의 One-Hot 및 Lookup 처리 방식, 그리고 Softmax 활성화 함수와 결합되었을 때 일어나는 역전파 기울기 상쇄($\hat{\mathbf{y}} - \mathbf{y}$) 미분 유도 과정을 다룬다.

<br/>

---

### 1. 토큰의 One-Hot 표현과 룩업(Lookup) 메커니즘
<br/>

LLM에서 정답 토큰 ID(예: 인덱스 $c$)는 해당 위치만 1이고 나머지 $K-1$개 위치는 0인 <strong>One-Hot 벡터 $\mathbf{y}$</strong>로 취급된다.

- **입력 시 (Embedding Lookup)**: 입력 단에서는 메모리 절약을 위해 $K$차원 One-Hot 벡터를 거대한 임베딩 행렬에 직접 행렬 곱하지 않고, 토큰 ID($c$)에 해당하는 행을 그대로 읽어오는 **Embedding Lookup** 방식을 사용한다.
- **출력 시 (Target Label)**: 예측 확률 벡터 $\hat{\mathbf{y}}$와 비교되는 정답 라벨 $\mathbf{y}$는 원-핫 벡터이며, 정답 위치 $y_c = 1$, 오답 위치 $y_k = 0$ ($k \neq c$)의 성질을 가진다.

<br/>

---

### 2. Multi-Class Cross-Entropy 손실 수식
<br/>

어휘 사전의 크기를 $K$ (예: 32,000개)라 하고, 모델의 출력 로짓 $\mathbf{z}$에 Softmax 함수를 적용한 예측 확률을 $\hat{y}_k = \frac{e^{z_k}}{\sum_{j=1}^{K} e^{z_j}}$라 할 때, 교차 엔트로피 손실식은 다음과 같다.

$$
L(\hat{\mathbf{y}}, \mathbf{y}) = - \sum_{k=1}^{K} y_k \ln(\hat{y}_k)
$$

정답 위치 $c$만 $y_c = 1$이고 나머지는 0이므로, 손실식은 정답 토큰의 확률 $\hat{y}_c$에 대한 단일 음의 로그값으로 대폭 단순화된다.

$$
L = - \ln(\hat{y}_c) = -z_c + \ln\left(\sum_{j=1}^{K} e^{z_j}\right)
$$

<br/>

---

### 3. Softmax-Log 상쇄 미분 유도 (Derivation of $\hat{\mathbf{y}} - \mathbf{y}$)
<br/>

손실 $L = -z_c + \ln\left(\sum e^{z_j}\right)$를 각 로짓 $z_k$에 대해 직접 편미분하면, 지수함수($e^z$)와 로그함수($\ln$)가 연쇄 법칙 과정에서 서로를 완벽하게 상쇄하여 경쾌한 기울기 결과가 유도된다.

#### 1) 정답 위치 ($k = c$) 편미분
$$
\frac{\partial L}{\partial z_c} = -1 + \frac{e^{z_c}}{\sum_{j=1}^{K} e^{z_j}} = -1 + \hat{y}_c = \hat{y}_c - 1
$$

#### 2) 오답 위치 ($k \neq c$) 편미분
$$
\frac{\partial L}{\partial z_k} = 0 + \frac{e^{z_k}}{\sum_{j=1}^{K} e^{z_j}} = \hat{y}_k = \hat{y}_k - 0
$$

#### 3) 전체 벡터 국소 기울기 ($\delta$)
이를 $K$차원 전체 로짓 벡터 $\mathbf{z}$에 대한 편미분 벡터로 묶으면 다음과 같이 단순 뺄셈(Residual) 벡터로 귀결된다.

$$
\frac{\partial L}{\partial \mathbf{z}} = \begin{bmatrix} \hat{y}_1 - 0 \\ \vdots \\ \hat{y}_c - 1 \\ \vdots \\ \hat{y}_K - 0 \end{bmatrix} = \mathbf{\hat{y}} - \mathbf{y}
$$

- 아무리 수만 차원의 다중 클래스 오차일지라도 역전파 시 출력층에 전달되는 국소 기울기는 **$(\text{예측 확률 벡터} - \text{정답 원핫 벡터})$**라는 순수한 뺄셈으로 전달된다.
- 이 경쾌한 미분 결과 덕분에 PyTorch 커널이나 Megatron-LM 등의 대규모 LLM 엔진에서도 `softmax(logits) - one_hot(target)` 단 한 줄의 고속 GPU 연산으로 오차 신호를 산출하여 하위 레이어로 역전파할 수 있다.
