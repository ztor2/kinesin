### Intro
<br/>

- 심층 신경망(Deep Neural Networks, DNN) 학습의 본질적 목표는 수많은 파라미터(가중치)를 갱신하여 예측값과 실제 정답 간의 오차를 최소화하는 것이다.<br/>
- 파라미터의 업데이트 방향과 크기를 결정하기 위해서는 오차 함수(Loss Function)에 대한 각 개별 가중치의 기울기(Gradient)를 정확히 산출해야 한다.<br/>
- 초기 신경망 연구에서는 가중치를 미세하게 변경하며 오차 변화를 측정하는 수치적 미분(Numerical Differentiation)을 시도했으나, 이는 파라미터 수에 비례하는 막대한 연산 비용을 요구하여 한계에 직면했다.<br/>
- 이를 극복하기 위해 다층 합성함수의 미분 원리인 <strong>연쇄 법칙(Chain Rule)</strong>을 도입하여, 출력층에서 입력층 방향으로 오차 민감도를 역방향 전파하며 기울기를 산출하는 <strong>역전파(Backpropagation)</strong> 알고리즘이 정립되었다.<br/>
- 오늘날 수조 개의 파라미터를 지닌 거대 언어 모델(LLM) 역시 이 역전파 알고리즘을 기반으로 최적화 및 학습이 이루어진다.<br/><br/>

본 문서에서는 순전파(Forward Pass)와 손실 산출, 역전파를 통한 기울기 도출의 수학적 과정, 그리고 비선형 활성화 함수가 가지는 필수적 역할을 분석한다.

<br/>

### Forward Pass & Loss Function
<br/><br/>

> <i>신경망의 순전파는 입력 데이터가 다수의 은닉층을 차례로 통과하며 최종 예측값을 도출하는 일련의 합성함수 연산 과정이다.</i> <br/>
<br/>

순전파 단계에서 특정 층(Layer) $l$의 출력 $\mathbf{h}_l$은 이전 층의 출력 $\mathbf{h}_{l-1}$에 가중치 행렬 $W_l$을 곱하고 편향 $b_l$을 더하는 선형 변환 후, 비선형 활성화 함수 $f$를 통과하여 계산된다. 

<br/>
$$
\mathbf{z}_l = W_l \mathbf{h}_{l-1} + b_l
$$
$$
\mathbf{h}_l = f(\mathbf{z}_l)
$$
<br/>

입력 데이터 $\mathbf{x}$가 최종 출력층을 통과하여 도출된 예측값을 $\hat{\mathbf{y}}$라 할 때, 모델의 성능은 예측값과 실제 정답 $\mathbf{y}$ 간의 차이를 정량화하는 <strong>손실 함수(Loss Function, $L$)</strong>에 의해 평가된다. 회귀 문제에서는 주로 평균 제곱 오차(MSE), 분류 및 언어 모델에서는 교차 엔트로피(Cross-Entropy)가 활용된다.

<br/>
$$
L = \text{Loss}(\hat{\mathbf{y}}, \mathbf{y})
$$
<br/>

이 손실 $L$의 값을 최소화하는 최적의 $W$와 $b$를 찾는 것이 딥러닝 학습의 최종 목표다.

<br/>

### Backward Pass & Chain Rule
<br/>

역전파는 총 오차 $L$에 대해 특정 가중치 $W_l$이 얼마나 기여했는지, 즉 오차 민감도를 나타내는 편미분 $\frac{\partial L}{\partial W_l}$을 구하는 과정이다. 
심층 신경망은 여러 함수가 중첩된 구조이므로, 해석적 미분을 위해 수학의 <strong>연쇄 법칙(Chain Rule)</strong>이 필연적으로 적용된다. 

<br/>
$$
\frac{\partial L}{\partial W_l} = \frac{\partial L}{\partial \mathbf{h}_l} \frac{\partial \mathbf{h}_l}{\partial \mathbf{z}_l} \frac{\partial \mathbf{z}_l}{\partial W_l}
$$
<br/>

위 수식에서 각 항은 다음과 같은 물리적 의미를 지닌다.
- $\frac{\partial L}{\partial \mathbf{h}_l}$ : 상위 층(출력층 방향)에서 현재 층으로 누적되어 전달된 <strong>전역 오차 신호(Global Error Signal)</strong>.
- $\frac{\partial \mathbf{h}_l}{\partial \mathbf{z}_l}$ : 현재 층 활성화 함수의 국소적 변화율(Local Gradient).
- $\frac{\partial \mathbf{z}_l}{\partial W_l}$ : 순전파 시 입력되었던 이전 층의 데이터 $\mathbf{h}_{l-1}$. 즉, 과거 입력값의 크기가 가중치의 책임 정도(기울기)를 결정하는 요인으로 작용한다.

역전파 알고리즘은 출력층에서부터 시작하여 이 연쇄 곱셈을 수행한다. 이미 계산된 상위 층의 오차 신호를 하위 층이 <strong>재사용</strong>하기 때문에, 순방향 연산을 반복할 필요 없이 단 한 번의 역방향 패스만으로 모든 파라미터의 기울기를 효율적으로 동시에 산출할 수 있다. 

산출된 기울기는 학습률(Learning Rate, $\eta$)과 결합되어 가중치 갱신 공식에 적용된다.

<br/>
$$
W_l^{(new)} = W_l^{(old)} - \eta \frac{\partial L}{\partial W_l}
$$
<br/>

### Differentiability of Non-linear Activation
<br/>

선형 연산만 중첩될 경우 신경망은 단일 선형 변환식으로 축소되므로, 다차원 공간의 복잡한 패턴 분리를 위해서는 반드시 비선형 활성화 함수가 요구된다. 
역전파 연산이 입력층까지 중단 없이 수행되기 위해서는, 네트워크를 구성하는 비선형 함수가 수학적으로 <strong>미분 가능(Differentiable)</strong>해야 한다. 

- 초기 딥러닝에서 주로 사용된 Sigmoid는 미분 가능하나 양 극단에서 기울기가 0에 수렴하는 기울기 소실(Vanishing Gradient) 문제가 존재했다.
- 현대 모델에 표준적으로 도입되는 ReLU($\max(0, x)$)나 최신 LLM의 SwiGLU 등은 연산이 단순하면서도 대부분의 영역에서 일정한 기울기를 유지한다.
- 이들 함수는 뾰족한 점(Kink)이나 특정 비활성 구간을 제외하면 완벽히 미분 가능하여, 역전파 과정에서 연쇄 법칙의 고리를 잇는 핵심 매개체로 작동한다.

<br/>

### Boundary of Backpropagation in LLMs
<br/>

LLM 역시 수백억 개의 파라미터와 비선형 함수가 결합된 거대한 단일 합성함수이다. 다만, 최적화가 적용되는 영역과 그렇지 않은 영역을 구조적으로 명확히 구분해야 한다.

- <strong>순수 함수 및 역전파 영역</strong>: 입력 토큰이 트랜스포머의 다중 레이어를 거쳐 어휘 사전(Vocabulary) 전체에 대한 '확률 분포(Logits)'를 산출하는 단계까지는 연속적이고 미분 가능한 영역이다. 학습(Training) 시에는 샘플링을 거치지 않고, 이 확률 분포 자체와 실제 정답 간의 손실을 계산하여 역전파를 수행한다.
- <strong>샘플링 후처리 영역</strong>: 도출된 확률 분포를 기반으로 난수를 발생시켜 단 하나의 단어를 확정하는 행위(Top-k, Top-p 등)는 이산적 선택이 개입된 확률적 샘플링이다. 이는 수학적 미분이 불가능하므로 역전파 시스템 외곽에 위치하는 후처리(Post-processing)로 분류된다.

### Comparison Summary
<br/>

순전파와 역전파의 주요 연산 특성을 요약하면 다음과 같다.

| 구분 | Forward Pass (순전파) | Backward Pass (역전파) |
| :--- | :--- | :--- |
| <strong>연산 방향</strong> | 입력층 $\rightarrow$ 출력층 | 출력층 $\rightarrow$ 입력층 |
| <strong>주요 목적</strong> | 예측값 도출 및 손실(Loss) 산출 | 각 파라미터의 오차 민감도(기울기) 산출 |
| <strong>수학적 원리</strong> | 선형 변환 및 비선형 활성화 함수 | 미적분학의 연쇄 법칙 (Chain Rule) |
| <strong>입력값의 역할</strong> | 다음 층으로 전달될 특징 추출 | 역방향 기울기 크기를 결정짓는 증폭기 |
| <strong>출력 결과물</strong> | 최종 예측 벡터 및 오차 스칼라 값 | 모든 가중치에 대한 기울기(Gradient) 텐서 |
